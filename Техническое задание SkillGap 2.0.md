# Техническое задание — SkillGap

## 1. Суть проекта

**SkillGap** — приложение внутри MAX для девятиклассников, которые уже рассматривают поступление на программу СПО.

Приложение помогает понять:

- кем можно работать после выбранной программы;
- какие вакансии начального уровня есть в регионе;
- какие навыки требуют работодатели;
- какие навыки найдены в примерной образовательной программе;
- какие востребованные навыки в анализируемом документе не найдены;
- на какую зарплату можно ориентироваться.

SkillGap не выбирает профессию за пользователя и не является полноценной профориентацией.

## 2. Охват

В приложении должны быть доступны:

- все регионы России;
- все профессии и специальности СПО из федерального справочника;
- актуальные и исторические коды программ;
- квалификации внутри программы;
- возможные стартовые профессии и должности.

Для каждого кода СПО нужна базовая связь:

> код программы → квалификации → возможные должности → запросы для поиска вакансий

## 3. Основной сценарий

1. Пользователь открывает SkillGap в MAX.
2. Выбирает регион.
3. Выбирает профессию или специальность СПО по названию либо коду.
4. При необходимости выбирает квалификацию.
5. Видит, кем можно работать после этой программы.
6. Запускает анализ рынка труда.
7. Получает требования работодателей, Skill Gap, зарплатную статистику и примеры вакансий.

## 4. Что должно быть в приложении

### Выбор направления

- поиск региона;
- поиск программы СПО по названию или коду;
- отображение названия, квалификаций и статуса программы;
- ссылка на федеральный источник программы.

### Возможные профессии

- список стартовых должностей после обучения;
- разделение должностей по квалификациям, если их несколько;
- пояснение, что это возможные направления работы, а не гарантия трудоустройства.

### Вакансии

- поиск вакансий в выбранном регионе;
- основной источник — «Работа России»;
- вакансии начального уровня, стажировки и позиции без опыта;
- исключение явно старших и руководящих позиций;
- несколько примеров вакансий со ссылками на источник;
- заметная отметка, если для демонстрации используются тестовые данные.

### Требования рынка

- список наиболее востребованных профессиональных навыков;
- частота каждого навыка в найденных вакансиях;
- количество вакансий, использованных для анализа;
- примеры требований работодателей.

### Образовательная программа

- анализ официальной примерной программы СПО;
- использование ФГОС, если примерная программа недоступна;
- отображение основных дисциплин, профессиональных модулей, компетенций и найденных навыков;
- ссылка на анализируемый документ.

### Skill Gap

Навыки из вакансий сопоставляются с содержанием образовательной программы. Для каждого навыка показывается один из статусов:

- **Найдено**;
- **Частично найдено**;
- **Не найдено в анализируемом документе/программе**.

Если совпадение найдено, пользователь должен увидеть подтверждающую дисциплину, модуль или фрагмент документа.

Нельзя утверждать, что конкретный колледж «не учит» навыку, если анализировалась только федеральная программа или ФГОС.

### Зарплаты

- зарплатный диапазон;
- медианная зарплата при наличии достаточных данных;
- количество вакансий, по которым рассчитана статистика;
- сообщение **«Нет данных»**, если зарплаты в вакансиях не указаны.

### Актуальность данных

Пользователь должен видеть:

- источник и дату получения вакансий;
- реальные, кэшированные или тестовые данные используются;
- название и ссылку на образовательный документ.

## 5. Основные экраны

1. **Выбор направления:** регион, программа СПО, квалификация, кнопка запуска анализа.
2. **Результат:** возможные профессии, требования рынка, Skill Gap и зарплаты.
3. **Вакансии:** подходящие вакансии с работодателем, зарплатой и ссылкой.
4. **Программа:** дисциплины, модули, навыки и официальный источник.

## 6. Можно добавить позже

- функцию **«Следить за рынком»** с уведомлениями о новых вакансиях и изменении требований;
- учебные планы конкретных колледжей;
- сравнение нескольких программ СПО.
